# Planet Whiskey NFTs

A sophisticated blockchain-based platform for whiskey barrel NFT investment, built on Solana with dual payment method support (SOL and Whiskey Tokens).

## 🚀 Recent Updates & Features

### Dual Payment System
- **SOL Payments**: Traditional Solana payments for NFT minting
- **Whiskey Token Payments**: Custom token-based payment system
- **Dynamic Pricing**: Collections can set different prices for both payment methods
- **Real-time Payment Method Selection**: Users can choose their preferred payment method during minting

### Professional Design Overhaul
- **Modern UI/UX**: Completely redesigned interface with professional amber/whiskey color scheme
- **Responsive Design**: Optimized for all device sizes
- **Hero Sections**: Beautiful landing pages with background imagery
- **Enhanced Admin Interface**: Professional admin portal with improved navigation and styling
- **Payment Method Buttons**: Distinctive SOL and Whiskey coin payment options

### Enhanced Admin Features
- **Admin Button**: Quick access to admin panel for authenticated users
- **Improved Navigation**: Better admin layout with clear section indicators
- **Professional Login**: Redesigned admin login experience
- **Real-time Session Management**: Seamless authentication handling

## 🛠 Technical Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Blockchain**: Solana, Anchor Framework
- **Database**: MongoDB with Mongoose
- **Authentication**: Iron Session
- **Payment Methods**: 
  - SOL (Native Solana)
  - Whiskey Tokens (Custom SPL Token)

## 📦 Installation & Setup

```bash
# Clone the repository
git clone [repository-url]
cd WhiskeyPlanetNfts

# Install dependencies
cd planet-whiskey-nfts
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your configuration

# Run development server
npm run dev
```
